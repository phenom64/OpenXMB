# OpenXMB 0.3.0 Beta 3

Beta 3 improves everyday media playback, XMB navigation and settings, and adds
an embedded Windows browser and working live language selection.

## What's changed since Beta 2

- Settings now use the XMB category and choice panes, with functional display,
  audio, input, media and appearance controls. Added a branded About screen,
  computer hardware information, and program and third-party licence notices.
  System Update remains a clearly labelled future feature.
- Music streams through FFmpeg with expanded support for M4A/AAC, ALAC, Opus and
  AIFF alongside existing formats and tracker playback. Improved seeking,
  buffering, pause and output-device switching. Navigation sounds can become
  quieter during music without reducing the song's volume.
- Music folders retain their navigation hierarchy and use the correct folder
  and song artwork. Added Songs, Albums, Artists and Playlists views, playlist
  creation and editing, and queue actions. Returning to the currently playing
  song preserves its playback position and pause state.
- Wave and Flow visualisers respond to the playing music. Flow adds varied
  long-running terrain, folds, light washes and soft square particles, with
  adaptive travel speed and gentle camera sway and rotation. Visualiser names
  fade after three seconds. Fixed blurred player backgrounds and the wave jump
  when returning to the crossbar.
- Improved embedded album artwork, photo and video thumbnails, JPEG decoding,
  and fallback icons while previews load.
- Video can upload native YUV frames, reducing frame-transfer work. Fixed audio
  starvation and added automatic software fallback when a hardware decoder
  cannot sustain playback. Pausing now waits for in-flight audio before freezing
  playback. Hardware results still depend on the host.
- Windows browsing now embeds WebView2 inside the shell. Browser options use
  shell controls, and focusing an editable web field opens the on-screen keyboard.
- Controller handling better respects button release and configured bindings.
  Added matching glossy Xbox artwork for face buttons, Start, shoulders,
  triggers and other physical controls.
- Live language changes apply to settings and native controls, with persisted
  selection and script-capable text rendering. Twelve language packs are
  included: British English, German, French, Hindi, Polish, Indonesian, Spanish,
  Japanese, Simplified Chinese, Traditional Chinese, Korean and Russian.
- Startup audio can finish during the intro and warning animations. The
  photosensitivity warning is dismissible, and the startup wave eases into motion.
- `--force-dir` selects a home-style demo directory for one run, routing Music,
  Pictures/Photos and Videos/Movies to their corresponding categories. Lowercase
  folder names and flat media directories are also supported. Saved library
  preferences remain unchanged.
- Updated engine presentation synchronization and swapchain capability handling,
  including safe semaphore selection across swapchain recreation. Improved
  overlay texture lifetime during scene transitions and live anti-aliasing changes.
- Added a portable Linux archive with bundled application libraries, media and
  document helpers, browser resources and fonts. Release checks exercise the same
  archive on Ubuntu, Fedora and Arch Linux.

## Downloads

- Ubuntu 24.04 and compatible SynOS installations, x86-64: `openxmb_0.3.0.beta.3_amd64.deb`
- Linux x86-64 portable: `OpenXMB-0.3.0-beta.3-linux-x86_64.tar.gz`
- Windows 10 or 11 x86-64 portable: `OpenXMB-0.3.0-beta.3-windows-x86_64.zip`
- macOS 15 or later, Intel and Apple silicon: `OpenXMB-0.3.0-beta.3-macos-universal.dmg`

Verify downloads against `SHA256SUMS` in the release assets. The DEB declares
its runtime dependencies and is built on Ubuntu 24.04. The portable archive
requires glibc 2.39 or newer and a working host Vulkan driver; run its `OpenXMB`
launcher after extraction. The embedded browser also needs a host EGL driver.
It does not require FUSE. See the included portable
notes for browser sandbox permissions on systems that restrict user namespaces.
The macOS app has an ad-hoc signature and is not notarised; opening it may require
approval in Privacy & Security.

## Known limitations

- This is a beta; physical-device performance and platform behaviour need further testing.
- Translations are machine-assisted and have not all received native-speaker review.
- OpenGL ES, H700/RG34XX and handheld support remain deferred.
- Bitmap video subtitles and hardware-context libretro cores are not yet supported.
- P3T support covers the implemented feature subset. Native Wayland browser input
  and protected-disc playback require further work.
- Account, friend and trophy screens use local data; online services are not implemented.
