# OpenXMB 0.2.0 Beta 2

Beta 2 expands the desktop shell with new media tools, themes and integrations.

## What's new

- A refreshed 1920×1080 crossbar with updated icons, text effects, dialogs,
  on-screen keyboard and animated backgrounds.
- Theme Settings can import and preview theme packs, apply individual components,
  capture custom themes and restore your selection after restarting.
- Music playback now includes playlists, metadata and artwork, shuffle and repeat,
  seeking, volume controls and visualizers. Playback continues when you return to
  the crossbar.
- Photo viewing adds slideshows, zoom, rotation, wallpaper and editing actions.
  PDF and comic documents support page navigation and zoom; PDF viewing requires
  Poppler tools.
- Video playback adds native controls, seeking, speed and frame controls, audio
  tracks and text subtitles.
- Local profiles, game and application libraries, favorites and history bring
  your content into the crossbar.
- Desktop integrations include a browser, a software libretro host and
  mounted-disc playback. On Linux/X11, the optional embedded browser uses
  WebKitGTK; other configurations can use a system browser.

## Downloads

The planned release packages are:

- SynOS and Ubuntu x86-64: `openxmb_0.2.0~beta.2_amd64.deb`
- Windows x64 portable: `OpenXMB-0.2.0-beta.2-windows-x86_64.zip`
- macOS 15 or later, Intel and Apple silicon: `OpenXMB-0.2.0-beta.2-macos-universal.dmg`

Check the release assets for available downloads. The planned macOS app uses an
ad-hoc signature and is not notarized, so macOS may require you to approve it in
Privacy & Security before opening it.

## Known limitations

- This is a beta. Windows and macOS runtime behavior and physical-device
  performance need further testing.
- OpenGL ES, H700/RG34XX and handheld support are deferred.
- Hardware video decoding, bitmap video subtitles and hardware-context libretro
  cores are not yet supported.
- Theme compatibility is limited to the implemented P3T features. Native Wayland
  browser input and protected-disc playback require further work.
- Online account, friend and trophy services are not implemented; those screens
  use local data.
